# CRUD checklist

#### *(using springboot)*





### 

#### installation and setup





1. download this project as an archive having pgAdmin pre-installed

   ---
2. create the table named "tasks" in pgAdmin with attributes: id (PRIMARY KEY), title, comment, done (the default false)

   ---
3. redact the application.properties file, inserting your username and password from pgAdmin to connect to the database

   ---
4. once the program is built and is running, open the local link: http://localhost:8080/tasks
to access your checklist

   ---
5. ###### Enjoy! :D
